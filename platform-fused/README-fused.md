# platform-fused —— 三平台融合版

本目录是 **SchematicForge EVSE 2.7.0** 的改进分支，用于把三个 AI 平台
（GPT5.6 / GPT6 / Qwen3.8）的优点融合到一个可交付平台上。

## 与原版 2.7.0 的关系

底座取自 `SchematicForge EVSE 2.7.0`（git HEAD），未改动原始仓库。
本目录共 21 个文件相对该基线有改动，全部以 `v2.7.1-FIX-*` / `v2.7.1-INTEG-*`
注释标注，便于逐条追溯。

## 主要改进

1. **BOM 采用 Qwen3.8 样式**：新增 `engine/bom-library.js`（覆盖 66/66 器件类别），
   BOM 由 8 列扩至 12 列（信任列 8 + 参考知识列 4），并新增交互式
   `*_BOM.html`，厂商参考资料链接可点击跳转。
   链接性质如实标注（厂商官网 / 检索入口），不把首页伪装成型号级手册。
2. **AI 识图审图闭环**：`buildCase()` 增加 `drawingEvidence`，把图幅、器件/走线/
   跨页符计数、反读审计与视觉质量结论一并交给 AI，使 AI 具备真正的读图依据。
3. **线号体系**：线号由 `circuitId` 确定性派生（CCT-0125 → W0125），图面标注与
   端子接线表完全一致；线号在编译期注册为 Drawing IR 注记，因此通过平台的
   反读审计。
4. **电气缺陷修复**：辅助电源自锁死、急停硬线切断、交流电能表规格错标、
   图册图号重复、越界档位欠选不上图、CLI 不披露阻断原因。

## 验证

- 完整回归：325 例 / 324 通过 / 1 跳过 / 0 失败（与未修改基线一致）
- 5 标准 × 4 桩型 = 20/20 组合项目闸门 PASS
- 视觉审计 VIS-003/004/005 全为 0

`_verify/` 目录保存本次工作的验证脚本与文档生成脚本，可复跑复核。

## 边界声明

输出仍为方案级自动原理图（`CONCEPT_DRAFT—PROFESSIONAL_REVIEW_REQUIRED`），
**不是**生产图、施工图、设备报价、保护整定书、型式试验结论或任何标准符合性证明。
短路计算、选择性配合、载流量与压降、绝缘配合、型式试验与专业签发仍须由具备
相应资格的人员完成。
